# Reinforcement-learning-and-Optimizations

This repository includes runnable reference implementations for:

- Dynamic Programming (Policy Iteration, Value Iteration)
- REINFORCE (Monte Carlo Policy Gradient)
- PPO (Proximal Policy Optimization)
- TRPO (Trust Region Policy Optimization)

## Quick start

```bash
python rl_algorithms.py
```

## Notebook

Open and run:

- `notebooks/rl_algorithms_demo.ipynb`

## Dependency

- Python 3.9+
- `numpy`

Install dependency:

```bash
pip install numpy
```
